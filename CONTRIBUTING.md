# Участие в разработке xmath

Спасибо за интерес к проекту! Правила простые.

1. Создайте issue или обсудите идею, прежде чем браться за крупное изменение.
2. Сделайте форк, создайте ветку от `main`, внесите изменения и откройте pull request.
3. Перед отправкой проверьте:
   ```bash
   cargo fmt --all
   cargo clippy --workspace --all-targets
   cargo test --workspace
   shellcheck install.sh      # если меняли установщик
   ```
4. Добавляйте тесты для нового поведения ядра (`crates/xmath-core`).
5. Поведение должно соответствовать Mathcad 15 (классическая версия, не Prime); отклонения описывайте в PR.
6. Не копируйте код, графику и логотипы Mathcad или PTC.

Структура: `xmath-core` — движок, `xmath-cli` — консольная утилита, `xmath-gui` — приложение,
`xmath-mcp` — MCP-сервер, `skills/xmath` — навык для ИИ.

Сборка и установка из локального каталога: `./install.sh --from-local`.

Вклад публикуется под лицензией MIT OR Apache-2.0.
