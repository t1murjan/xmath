# Единицы измерения

xmath следует модели единиц Mathcad 15: размерность хранится как семь показателей СИ
(m, kg, s, A, K, mol, cd) с шагом 1/12, вычисления всегда идут в СИ, а единицы влияют
только на отображение.

## Таблица единиц

Полный список: инструмент MCP `list_units` или диалог «Вставить единицу» (Ctrl+U).
Имена как в Mathcad: `gm` - грамм (`g` - ускорение свободного падения), `hr` - час, `L` - литр,
`tonne`/`mton` - метрическая тонна, `ton` - короткая тонна (2000 lb), `tonf`, `kip`, `lbf`, `psi`,
`kgf`, `at` (= кгс/см²), `mmHg`, `mmH2O`, `BTU`, `hp`. Определение пользователя имеет приоритет над
именем единицы (`R := 8.314` затеняет ранкин).

## Температура

| Запись | Смысл |
|---|---|
| `K`, `R` | абсолютные единицы (кельвин, ранкин) |
| `°C` / `degC`, `°F` / `degF` | шкалы со смещением |
| `Δ°C`, `Δ°F` (`ΔdegC`, `ΔdegF`) | разности температур |

Как в Mathcad, смещение применяется только (а) когда `°C`/`°F` - последний множитель скалярного
числа: `T := 25 °C` хранит 298.15 K (`x °C` = `(x + 273.15) K`, `x °F` = `(x + 459.67)·5/9 K`);
(б) как единица отображения: `T = °C` показывает `(T - 273.15 K)/K`, `T = °F` даёт 77.
В остальных местах (`5 °C/s`, `°C^2`, голое `°C`) имя ведёт себя как `K` (`Δ°C`).
Разность двух температур - в кельвинах; прибавляйте разности через `Δ°C`: `T + 10 Δ°C`.
Для не-температурных величин смещение игнорируется.

## Автоматические единицы результата

1. Размерность, точно совпадающая с производной единицей, показывается ей:
   `N Pa J W C V Ω S F H Wb T`. Энергия и момент - всегда `J`; частота остаётся `1/s`.
2. Иначе выбирается запись с наименьшим числом множителей из «базовые единицы» и
   «одна производная в степени ±1 x базовые»: `Pa·s`, `W/(m·K)`, `V/m`, `kg/m^3`, `m^2/s`.
3. При равенстве побеждают базовые (`kg·m^2`), кроме `N`, `Pa`, `W` в знаменателе без массы
   (`N/m`, `W/m^2`). Порядок: производная, kg, m, s, A, K, ...
4. `expr = unit` показывает число в указанной единице; если размерность отличается, остаток
   дописывается: `5 N = kg` даёт `5 m/s^2` (то есть 5 м/с²·кг).

## Система единиц (Tools - Worksheet Options - Unit System)

Поле `unit_system` в `format` файла (`si` по умолчанию, `mks`, `cgs`, `us`; старые файлы без поля
читаются как СИ). Меняется только отображение автоматических единиц: CGS - `cm gm s`, `dyne`, `erg`;
US - `ft lb s R`, `lbf`, `psi`, `hp`; MKS отображается как СИ.
